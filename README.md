# 🃏 Blackjack Game Using JavaScript

A simple **Blackjack Game** built using **HTML, CSS, and JavaScript**. 🎮

This project was created to practice JavaScript fundamentals and build an interactive browser game.

## 🎯 Features

* 🎴 Draw random cards
* ➕ Calculate the sum of cards
* 🃏 Blackjack detection
* 💥 Game over when the sum exceeds 21
* 🔄 Start a new game

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📚 What I Learned

* Variables and functions
* Arrays
* Conditional statements
* DOM manipulation
* Event handling
